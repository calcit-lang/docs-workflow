# Calcit 0.13.77 alignment / 对齐 Calcit 0.13.77

Timestamp / 时间：2026-09-04T17:55:47Z

## 中文

- 将模板声明的 Calcit 与 `@calcit/procs` 从 0.13.68 同步升级到已发布的 0.13.77。
- 将 Alerts/Reel/Markdown/Router/UI/Respo 对齐到已发布的 0.10.28/0.6.12/0.4.30/0.8.9/0.7.15/0.16.90；其中 Alerts 的具体 `modal-actions-plugin` 返回 schema 满足 0.13.77 的 nominal method 检查。
- 将 `find-target` 的缺失与命中结果改为显式 `Option` 构造，在受信任的浏览器键盘事件边界收窄 key/meta/ctrl 字段，并通过 `reel-schema/read-field` 读取 store。
- 当前已发布的 Respo 0.16.90 仍使 check-only 留下 4 条依赖侧告警；临时对照已合并 #132 后仍有 3 条 `respo.comp.global-keydown` 告警，因此本提交只是可恢复检查点，不能作为发布验收。
- 保持模板版本 0.0.25、文档 API、浏览器入口和部署行为不变。
- 使用严格 caps 与工具链核验、Calcit 静态分析、JS codegen、Node 24/Yarn 4 immutable install、Vite 和 mdBook 构建验证升级。

## English

- Upgrade the template's declared Calcit and `@calcit/procs` versions together from 0.13.68 to the published 0.13.77 release.
- Align Alerts/Reel/Markdown/Router/UI/Respo to their published 0.10.28/0.6.12/0.4.30/0.8.9/0.7.15/0.16.90 set; Alerts' concrete `modal-actions-plugin` return schema satisfies 0.13.77 nominal method checking.
- Use explicit `Option` constructors in `find-target`, narrow key/meta/ctrl at the trusted browser keyboard-event boundary, and read the store through `reel-schema/read-field`.
- Published Respo 0.16.90 still leaves four dependency warnings in check-only; a temporary comparison against merged #132 still leaves three `respo.comp.global-keydown` warnings. This commit is a recoverable checkpoint, not release acceptance.
- Keep template version 0.0.25, documented API, browser entry, and deployment behavior unchanged.
- Validate the upgrade with strict caps/toolchain verification, Calcit static analysis, JS codegen, Node 24/Yarn 4 immutable install, Vite, and mdBook builds.
