# 对齐 Calcit 0.13.68 生态 / Align the Calcit 0.13.68 ecosystem

## 中文

- 将 Calcit 与 `@calcit/procs` 对齐到 0.13.68，并升级 Respo/alerts/reel/markdown/router/ui 到当前稳定 tag。
- GitHub Actions 改用公开稳定的 `setup-calcit@v1`，不再固定内部 commit hash。
- CI 启用 `caps --strict --ci`，阻止 docs-workflow 再向 guidebook 等下游传播依赖分歧。
- 使用 0.13.51 完成最后兼容迁移，为 `load-doc` 声明 `Expr<String> -> Expr<String>` 与编译期 `:fs-read` 的严格宏契约，再由 0.13.68 验证。
- 将 updater 中已退役的 `tag-match` 改为 `match`，使 deprecated 分析归零。

## English

- Align Calcit and `@calcit/procs` at 0.13.68 and upgrade Respo/alerts/reel/markdown/router/ui to current stable tags.
- Use the public stable `setup-calcit@v1` action instead of pinning an internal commit hash.
- Enable `caps --strict --ci` so docs-workflow cannot reintroduce dependency divergence into guidebook and other consumers.
- Use 0.13.51 for the final compatibility migration, declaring `load-doc` as an `Expr<String> -> Expr<String>` macro with compile-time `:fs-read`, then validate it with 0.13.68.
- Replace the retired `tag-match` call in the updater with `match`, bringing deprecated analysis to zero.
