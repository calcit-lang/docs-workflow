# 0.0.26

- Upgrade the Calcit toolchain to 0.13.77 and align the released Respo dependency chain.
- Migrate modal actions, Option values, keyboard/browser FFI, Reel persistence, and list membership to current typed APIs.
- Add strict dependency, toolchain, quality, dynamic-method, and immutable Action revision checks in CI.

## 中文

- 将 Calcit 工具链升级至 0.13.77，并对齐已发布的 Respo 依赖链。
- 将弹窗动作、Option、键盘/浏览器 FFI、Reel 持久化和列表成员判断迁移至当前类型 API。
- 在 CI 中增加严格依赖、工具链、质量、动态方法与不可变 Action 提交检查。
